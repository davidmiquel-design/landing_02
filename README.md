# SHENKEN — landing page

Landing page for SHENKEN, a brutalist architecture studio. Nocturnal art direction,
scroll-driven animation (GSAP ScrollTrigger + Lenis), built with Vite.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

- `docs/ASSET_BRIEF.md` — brief for the images and videos generated with Magnific.
- `assets/source/` — upscaled master images and videos (not served directly).
